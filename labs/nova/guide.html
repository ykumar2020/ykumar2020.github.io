NOVA / WORKING PROTOTYPE

A teaching partner.
You keep the floor.

Nova is a local browser lecture player with live voice and a 3D teaching assistant. The website preview is a silent, scripted demonstration. Download the application to use live listening, spoken explanations, and your own slides.

Set up on Windows or Mac

  1. Install Node.js 22.16 or later and Python 3.11 or later. Extract the ZIP and open its folder in a terminal.
  2. Install dependencies and build the browser app:
    npm ci
python -m pip install pymupdf
npm run build
    For direct PowerPoint import on Windows, also install pywin32 and have Microsoft PowerPoint installed. On Mac, export slides to PDF first.
  3. Copy .env.example to .env and put your own OpenAI API key in OPENAI_API_KEY. The server keeps it out of the browser. Live API usage is billed to that key's project.
  4. Run npm start and open http://localhost:4317 in Chrome or Edge. The starter package includes three sample slides; upload your lecture.

Use it during a lecture

Click Connect live audio, allow the microphone, and inform your class that connected audio is processed by OpenAI. Choose a handoff of one, three, or five slides. Nova stays quiet until you directly address it or use a control.

  • “Nova, continue my lecture” starts the bounded handoff.
  • “Nova, explain this slide” starts one spoken explanation.
  • “Nova, stop”, the take-back button, or Esc returns control to you.

Anyone near the microphone can use the wake phrase; this is not voice authentication. Esc mutes output locally without waiting for speech recognition. Disconnect releases the microphone.

Slides, notes, and movement

PDF imports preserve slide appearance. Windows PowerPoint imports can also retrieve speaker notes. Slides are rendered as images, so native PowerPoint animations and embedded videos do not play. Instructor notes can be edited and exported. The TA receives the current slide image, text, notes, and bounded recent transcript for each authorized response.

The original 3D robot has procedural walking, gestures, blinking, and mouth movement driven by audio amplitude. It is not a photorealistic avatar or a phoneme-accurate facial rig. Rendering is capped at 30 fps, and reduced-motion preferences are supported.

What has been checked

Seven unit checks cover command parsing and speech permissions. Browser checks cover handoff, slide advancement, stopping delayed responses, notes, responsive layout, and reduced motion. Real WebRTC tests used generated classroom speech to check that ordinary speech did not trigger an answer, while a direct wake request and stop command did.

This is a supervised classroom prototype. Actual room acoustics, long teaching sessions, and the accuracy of every explanation have not been validated. The app operates inside its own browser lecture player; it is not an overlay for a separate desktop PowerPoint window.

Rehearsal mode works without a live API connection using the browser's installed voice. It reads supplied notes and does not answer new questions. Imported decks stay on the local machine; the public starter download does not include private lecture files, API keys, or classroom recordings.
